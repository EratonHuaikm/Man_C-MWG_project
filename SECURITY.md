# Politica di sicurezza

| Versione | Supportata |
| -------- | ---------- |
| latest   | :white_check_mark: |
| < 1.0    | :x: |

## Segnalazione di una vulnerabilità

Se individui una vulnerabilità di sicurezza, ti chiediamo di segnalarla in modo responsabile e privato esclusivamente tramite gli strumenti ufficiali di GitHub, senza pubblicare dettagli sensibili in spazi aperti.

1. **Dove inviare la segnalazione:** utilizza esclusivamente GitHub tramite la funzione **Report a vulnerability** nella scheda **Security** di questo repository (oppure, per segnalazioni generiche non sensibili, apri una **Issue** o una **Discussione** direttamente su GitHub).
2. **Cosa includere:** una descrizione chiara del problema, i passaggi per riprodurlo, l'impatto potenziale e l'eventuale versione interessata.
3. **Tempistiche di risposta:** riceverai un riscontro iniziale entro **48–72 ore** direttamente su GitHub e aggiornamenti sullo stato dell'analisi e della mitigazione.

Se la segnalazione viene confermata, lavoreremo a una correzione e coordineremo la divulgazione responsabile prima di renderla pubblica.
